> **10/7（三）20:00 開播。** 連結當天在社群公布，往下拉加入社群就會收到。

catime 和 Mori 野外筆記每天會自己找新聞、自己寫一篇。規則是我定的，之後排程自己跑。這場聊這兩個站：排程怎麼設、每一步叫哪個 AI、壞掉的時候怎麼辦，最後換成你自己的主題。

## 這晚會分享的

- **兩個例子**：
  - [catime](https://yazelin.github.io/catime/)：設定每小時生一隻 AI 貓，從一月底到現在三千多隻。實際上 GitHub 一天大概只跑四、五次，這也會講。畫圖的服務額度用完時，會自動改用 Gemini 畫。
  - [Mori 野外筆記](https://yazelin.github.io/mori-field-notes/)：每天讀 Hacker News 寫一篇觀察筆記，不畫圖，數字做成圖表。只要一把金鑰，最適合照著做。
- **兩個站的架構**：排程叫醒程式，程式一步一步叫服務，最後存進 repo，GitHub Pages 更新網站。兩個站都沒有自己的伺服器。
- **背後的兩個服務**：我自己架的 [gemini-web](https://github.com/yazelin/gemini-web)（文字、圖、音樂）和 [codex-image-service](https://github.com/yazelin/codex-image-service)（畫圖）。會講它們怎麼裝、怎麼發金鑰，還有 GitHub Actions 在 GitHub 的機器上跑，要怎麼連到我電腦上的服務。有 15 個站用到這兩個服務，整理在[服務總整理頁](/services/)。
- **會遇到的事**：排程常常晚好幾個小時；服務掛了要有退路；Mori 用 GitHub 內建的 token 推送，不會觸發部署網站的步驟，筆記寫好了卻沒上線。
- **換成你的**：沒有自己架服務，可以換成 Gemini、ChatGPT 或 Ollama Cloud 的 API。金鑰放 GitHub Secrets，用 `gh secret set` 設，不用開網頁。講義附三句咒語，照順序貼給 AI。

想跟著動手，開播前先準備好：一個能操作專案的 AI agent（Claude Code、Codex 或 Antigravity 擇一）、GitHub 帳號、GitHub CLI，以及一把 AI 服務的 API 金鑰。沒準備好也能直接來聽。
