> **10/7（三）20:00 開播。** 連結當天在社群公布，往下拉加入社群就會收到。

我有幾個網站，每天會自己找新聞、自己寫一篇、自己配圖，我沒有動手。這場把它們拆開來看：排程怎麼設、每一步呼叫哪個 AI、哪裡最容易壞，最後講怎麼照同一套做一個你自己的。

## 這晚會分享的

- **背後的兩個服務**：我自己架了兩個服務，一個負責文字、圖和音樂，一個專門畫圖，這些站每天都在呼叫它們。
- **四個例子**：
  - [catime](https://yazelin.github.io/catime/)：設定每小時生一隻 AI 貓，實際上 GitHub 大約幾個小時才跑一次，這也會講。
  - [格莉奇日記](https://yazelin.github.io/ai-brain-site/)：每天一篇，看新聞、寫日記、畫插圖。
  - [優理成長日記](https://yazelin.github.io/yori-growth-log/)：每天一篇四格漫畫。寫稿換過模型，我拿六個模型同一題各寫一篇比過。
  - [Mori 野外筆記](https://yazelin.github.io/mori-field-notes/)：每天一篇，不畫圖，數字直接做成圖表。
- **換成你的**：你沒有我架的服務，可以換成自己申請得到的 Gemini、ChatGPT 或 Ollama Cloud。做法跟上一場一樣：找一個參考、講要改什麼、給它資料。

想跟著動手，開播前先準備好：一個能操作專案的 AI agent（Claude Code、Codex 或 Antigravity 擇一）、GitHub 帳號，以及一把 AI 服務的 API 金鑰。沒準備好也能直接來聽。
