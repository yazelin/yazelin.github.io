想做個人網站，可以先找一個喜歡的。我在特效蒐集站看到 Bruno Simon 的 3D 作品集：開一台車，在島上逛他的作品。原始碼是公開的，我請 AI 拿它當底，換成我的作品、repo、角色和 catime 的貓。

## 這晚分享了什麼

- **找參考**：想像中的效果，先讓 AI 去找有沒有人做過、放在 GitHub Pages 上。
- **講要改什麼**：想參考哪一個、哪些地方要改，講得口語就好。
- **給資料**：要放上去的東西由你給，AI 才不會自己編。
- **玩一圈**：AI 說做好了之後，我自己開車逛，抓到了哪些問題。

想自己動手做，電腦上要先準備好：一個能操作專案的 AI agent（Claude Code、Codex 或 Antigravity 擇一）、Node.js 22 版、Git，以及 GitHub 帳號；有裝 GitHub CLI 的話，agent 可以自己幫你建 repo、開網站。大部分參考網站都要先用 Node.js 建置才能跑，所以這幾樣最好先裝好。錄影都在雲端資料夾，可以邊看邊做。

做出來的個人網站在這（電腦開比較好玩，手機也能玩）：[drive-folio-2025](https://yazelin.github.io/drive-folio-2025/)。
