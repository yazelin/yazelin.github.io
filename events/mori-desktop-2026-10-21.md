> 錄影切成 6 段可以單獨看，共約 97 分鐘：開場與安裝金鑰、五步流程與熱鍵、示範（信件、LINE、不吵架溝通術、生圖描述、請 AI 改 profile）、詞庫校正、設定頁與本機模型與換角色、直播記錄網站。
>
> 講義會後補了現場講到、原本沒寫的內容，放在第十五節：選取並複製的文字會一起送去整理、一人分飾多角、詞庫設定頁的自動建議、macOS 的狀況等。

Mori Desktop 是裝在桌面上的個人 AI 管家。這場講它的語音輸入：按一個鍵說話，文字轉好、整理完，貼進游標所在的視窗。

## 這場的內容

- **安裝**：Windows 與 Linux 的安裝檔，現場留 20 分鐘一起裝。直播中提供試用金鑰，結束後作廢。
- **口述**：示範純文字輸入、正式信件、LINE 貼文。同一段口語，換一份 profile 就換一種口氣。
- **自己改**：profile 是一個 Markdown 檔，現場示範新增一份。
- **詞庫校正**：同音錯字不再重複錯。
- **耳朵與腦袋**：語音轉文字與整理文字的模型都能換，雲端或本機自己選。
- **不吵架溝通術**：把不爽全部講出來，整理成對方聽得進去的訊息。
- **下一場預告**：Agent 模式與定時任務，另開一場。

## 限制

- 預設走 Groq 雲端，需要網路與金鑰，聲音與文字會送到 Groq。想全本機可換本機 Whisper 與 Ollama。
- Windows 安裝檔由 CI 建置，講者在 Windows 11 測過，可以用。沒有 macOS 版，只提供 Windows 與 Linux 安裝檔。
- Linux Wayland 的全域熱鍵有限制，講義有替代做法。
