視覺小說第一週　2026-09-09

在 Larch 上做一部自己的視覺小說

這份講義是給你回家自己做的。直播當晚我們花了很多時間在同一塊白板上一起玩，講述的部分因此講得比較零散。這份把它補齊，照著做，就算當天沒來也能從零做出一部能發佈的小說。

0先準備這三件

  1. 到 larch.ink 用 Google 登入，不用填資料。
  2. 到 創作者挑戰頁按報名。第二屆創作者挑戰期間（到 2026-09-20 截止），報名之後平台的 AI 功能可無限使用（AI 影片除外）。沒報名、或挑戰賽結束之後，每次配音、生圖都會扣松果幣，免費方案每月只有 20 枚。
  3. 用電腦的瀏覽器。白板要拖曳與縮放，手機做得很痛苦。
先報名再開始按生成。沒報名就按生成，扣掉的點數要不回來。當晚示範配音前特地停下來確認大家都報名了，就是為了這件事。

1Larch 的結構：專案、章節、卡片

三層，由大到小：

層級是什麼比喻
專案一部作品，也是素材、角色、設定的容器一套書
章節（白板）一張畫布，上面放卡片與連線一本
卡片玩家實際看到的一個畫面一頁

章節可以當「章」，也可以純粹當分類用。它們之間不會自動接下去：第一章演完不會自己跳到第二章，要在卡片上明確設定跳轉。

每個章節各自有一個「開始」起點。你可以把整個專案設計成一條連貫的長篇（只有一個真正的入口），也可以讓每一章都能獨立開始玩。兩種都行，差別在你要不要讓讀者從中間進來。

2創作順序：先寫結局，再往回推

手動排卡也好、之後交給 AI 也好，想故事的順序都一樣。卡在「不知道從哪裡開始寫」的時候，照這四步走：

  1. 先寫兩個結局。各一兩句，各自要有畫面。先寫開頭的人會卡在中間，先寫結局的人只要把路接過去。
  2. 回推那一個選擇。選項要兩邊都有人會選：說／不說、等／不等。一邊明顯比較好，那就只是一條走廊。
  3. 兩個角色，一人一個想要的東西。識別特徵各寫一行就夠：髮型、髮色、一件配件。別寫身家背景，第一部用不到。
  4. 場景最後才決定。場景只是他們碰面的地方，挑素材包裡現成的那張。
用當晚的範例拆一遍

先有兩個結局：「兩個店員把最後兩支黑輪分掉，好好道別了」與「隔天才發現他已經走了，沒有好好道別」。

回推：那個選擇是「說吧」或「明天再說」。

再回推：需要兩個角色（你、同事阿哲）與一個場景（打烊前的店）。

故事就這樣寫出來了，總共六到八張卡，十五分鐘做得完。

3三種卡

核心只有三種，其他都是進階。在白板空白處點兩下就能加卡。

卡做什麼什麼時候用
場景卡換背景換地點、換時間。沒換場景就不用再放一張，背景會一直延續下去
對話卡角色講話、配立繪與表情用量最大的一種
選擇卡跳出選項讓玩家選分支的地方

一張對話卡可以裝一整段對話

第一次做的人幾乎都會漏掉這件事，做出來自己玩會覺得卡卡的。一張對話卡預設只有一句，但只要場景沒換，你可以在同一張卡裡一直「加一句」，而且每一句可以是不同的人講的。

兩個人鬥嘴十句，正確做法是一張卡裝十句。排成十張卡玩起來是一樣的，差別在白板：十張卡很快就把畫面佔滿，之後要找卡、接線、改東西都麻煩，一段長對話還會被拆散在好幾張卡上。同一個場景，一張對話卡就解決了。

排法

場景 → 對話 → 對話 → 選擇 →（A 線）對話 → 結局 A ／（B 線）對話 → 結局 B。

選擇卡的選項可以放在畫面下方或中間。放下方比較像對話中的回應，放中間比較像真的要做一個決定。

4白板怎麼操作

動作怎麼做
縮放Ctrl + 滑鼠滾輪
移動畫布在空白處按住左鍵拖曳
加卡片空白處點兩下，選場景／對話／選擇
編輯卡片卡片上點兩下。左邊是預覽，右邊是設定
存檔Ctrl + S
框選多張按住 Shift 拉框
存檔卡在「儲存中」不動，按第二次就好。當晚實際發生過：第一次存檔畫面一直顯示儲存中、同步也沒發生，再按一次 Ctrl+S 立刻就完成了。看到卡住不要一直等。

多人同時編輯會互相蓋掉

共創白板上大家改同一組卡片時，後存的會蓋掉先存的。當晚的解法是：框選你要練習的那一組卡 → 右鍵 → 原地複製一份，然後改你自己那份。想搬遠一點就剪下、貼到白板空的地方。

5角色與表情

對話卡的設定由上到下就是四件事，記住順序就不會亂：

  1. 誰在說話，點一下換人。
  2. 用什麼表情，換人之後右邊會列出這個角色有的表情，點選即可。
  3. 他講什麼，台詞。
  4. 配音，見下一節。

平台內建十四包素材，角色與場景都有，匯入不扣點數。專案的「素材」頁切到「素材包」就能匯入。第一部作品全部用現成的就夠了。

活動頁那四個練習小故事的背景與角色，我另外畫成了一包「四個練習小故事・素材包」，在市集「素材」區搜名稱就有（四張背景、八個角色，NPC 各三種表情，免費）。

真的找不到適合的角色，才去「角色工作坊」生一個。那會扣點數（第二屆挑戰賽期間報名後可無限使用）。

6AI 配音

  1. 對話卡往下拉，展開進階。
  2. 台詞欄位右上角有一顆 AI 念台詞，或從進階展開，點音色與語氣。
  3. 清單預設只顯示十幾個，按檢視完整才會全部出來，總共 332 個音色，中文 34 個（2026-09-09 當天的數字，官方持續在加）。
  4. 每個音色都可以先試聽。挑好之後按生成，通常十秒內完成。
  5. 下面會出現播放鈕，聽一次。不滿意可以加情緒（流暢、自然等）重新生成。
台詞先確定再生成。它唸的就是當下那句台詞，改了字要重生。
挑音色一定要試聽。名字跟實際聽感可能會有一點差異，自己聽一句再決定。

7測試：三種播法

你想做的事怎麼做
只看某一張卡的效果那張卡按 Play，播完選「我看完了」回來改
從某一張往下走一整條線那張卡按 Play，播完選「繼續往下播」
從頭玩整章右上角的播放鈕。它會從你設定的開始那張卡起跑

設定起點：在卡片上按右鍵 → 設為開始。設好之後那張卡會出現一個小標籤。

已經是起點的卡，不能再設一次。當晚按右鍵設不了起點，我當時腦袋當機還想說奇怪是場景卡不能當起點嗎，後來 Yapi 在聊天室說明：那張本來就已經是起點了，所以那個選項才點不動。場景卡當然可以當起點，第 3 節那張圖裡的場景卡左上角就掛著「開始」標籤。

每一條分支都要自己走一遍。選擇卡的兩邊各走一次，確認讀起來連貫、選項的字沒有誤導。這件事 AI 幫不了你：它可以把卡排好，但「讀起來順不順」只有人看得出來。

8接上你的 AI Agent

做到這裡你已經會手動排卡了。接下來這一步，是把「拉卡片、接線、打字」整包交出去，你只負責想劇情與驗收。

  1. 回到專案列表頁，左下角你的帳號旁邊 → 偏好設定。
  2. 找到 AI 輔助 → Agent Key → 建立新的 key。
  3. 先取一個名字（例如「共創板專用」）。
  4. 選這把 key 能碰哪些專案。不指定就是全部都能碰。想保護手動維護的專案，就只勾要交給 AI 的那一個。
  5. 勾權限。八項分開勾：讀取、編輯、素材、AI 生成、匯出、版本，以及對外的預覽與發佈。沒勾讀取它就看不到裡面有什麼；沒勾發佈，你叫它發佈它也不會動。
  6. 按產生，然後複製 Skill，那是一段很長的說明文字，內含操作這個平台的完整方法。
  7. 把那段文字貼進 Claude Code、Codex 或 Antigravity，然後直接下指令。

可以這樣起手：

用內建素材包開一個新專案：打烊前老闆娘問常客要不要換一種茶。一個場景、兩個角色、一個選擇、兩個結局，設好標題畫面，做完發佈，給我市集網址。
那段 Skill 文字裡內嵌著你的 Agent Key，它等於你的帳號密碼。 拿到 key 的人不需要你的密碼就能用你的身分建卡、刪卡、發佈作品。當晚示範時 key 直接出現在直播畫面上，所以那把當場就刪掉了。key 外流的正確處理就是立刻刪除，刪掉即永久失效（刪完畫面若沒更新，重整一次）。

所以：不要貼進公開的對話、不要傳到群組、不要 commit 進 repo、不要在螢幕分享時點開它。

權限越大越好用，也越容易被搞爛。全勾的 key 能幫你做完所有事，出錯時也能把整個專案清空。自己衡量：常常手動編輯的專案，給它一把只讀的 key 就好。

9發佈與交件

  1. 發佈視窗裡勾「第二屆創作者挑戰」，那一勾就是報名參賽（2026-09-20 截止；之後的屆數請看官方活動頁）。
  2. 更新日誌寫清楚哪些是 AI 做的：素材、文案、配音，各自到什麼程度。
  3. 發佈完會拿到一個市集網址，免登入就能玩，可以直接分享。
發佈出去的是快照，不是即時鏡像。你之後改專案，市集上那一份不會跟著變，而且不會有任何提示。改完要再發佈一次。

症狀真正的原因
改完了，市集上還是舊的發佈是快照，要再發佈一次

11AI 導演：當晚實測與結論

白板有一個「AI 模式」，開了之後 AI 會把版子上所有卡片當素材，照你寫的提示詞即興演一齣。當晚我們全場一起丟卡片然後跑了兩次，沒有預期中那麼好玩。以下是當時哪幾件事沒做到，你自己要用的時候可以先避開。

當時的提示詞是「用白板上的卡片隨意推演劇情，每個卡片的人物都要出現到，大家一起出來開同樂會吧」。播出來的東西比較散：角色輪流亂入，沒有一條主線串著。

事後回頭看，有四件事沒做到

  • 提示詞在要求它散。「隨意推演」加上「每個人物都要出現到」，等於叫它把十幾個不同世界的角色塞進同一場戲，而且沒有收尾條件。
  • 白板上沒有場景卡。一張都沒有。沒有舞台，導演只能在對白之間跳。
  • 沒有主持人也沒有終點。沒有任何一張卡告訴它這場戲要往哪去、什麼時候該結束。
  • 大家丟的句子彼此無關。來自五個不同的世界，沒有共同場景、沒有人物關係。素材本身就接不起來。

要用 AI 導演，先給它這四樣

  1. 一張場景卡當舞台。
  2. 一個主持人角色，負責把場子交給下一個人。
  3. 提示詞要有場合、規則、收尾條件：一次只讓一到兩個人講話、講完換下一組、幾句之內收在哪一句話。把「隨意」拿掉。
  4. 丟素材的時候先定一個世界。大家各挑各的世界，導演救不回來。

13回家的四個練習

每一個都是一個場景、兩個角色、一個選擇、兩個結局，六到八張卡，十五分鐘做得完。背景全部用內建素材，不用生圖。

練習故事背景
一、關東煮前面收銀機關了，同事阿哲說「有件事我一直沒跟你講」。選「說吧」或「明天再說」霓虹夜城
二、茶館的最後一杯常客每天點同一杯，今天老闆娘問「今天想換一種嗎」星軌街屋・雨後夜巷
三、診療所的號碼牌診所要關了，最後一號還沒叫到。選「明天再來」或「我可以等」雨後急診走廊
四、霧港的信一封寫錯地址的信，管理員問「要拆嗎」霧港渡輪總站・藍時

完整的故事內容在活動頁。不想用內建素材的話，這四個故事的背景與角色我另外畫成一包「四個練習小故事・素材包」，市集「素材」區搜名稱就有，免費。做完一個，你就有一個免登入可以分享的網址了。
