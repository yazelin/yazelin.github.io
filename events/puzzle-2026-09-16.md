## 謎題的形狀（刻意做小）

- 三個場景 A、B、C，可以來回。
- 三件物品：A 撿到的在 B 用，B 撿到的在 C 用，C 解開就通關。
- 有一條線索要回頭：拿到東西之後得回前一個場景看某樣東西，這就是官方點名的場景往返。
- 走錯順序只提示，不卡死；沒通關的結局能回標題重來。
- 最多兩個有立繪的角色，卡片 25 張以內，遊戲時間 5 到 10 分鐘。

規模鎖死是因為 90 分鐘要做完加試玩。角色多一個就多一組表情要生，場景多一個就多一輪走查。

## 解謎規格表（開場十五分鐘要填完的那張）

填完整段貼給 Agent 就能開工。空白的欄位由 Agent 自己補，**粗體的一定要人填**。

**一、規模（先鎖死，不討論）**

| 項目 | 上限 | 為什麼 |
|---|---|---|
| 遊戲時間 | 5 到 10 分鐘 | 官方建議，也是評審願意玩完的長度 |
| 場景 | **3 個**（A、B、C） | 三個剛好能做「來回」，四個就做不完 |
| 角色 | **最多 2 個有立繪的**，旁白不算 | 每多一個角色多一組表情要生 |
| 物品 | **3 件** | 一件在 A 撿、一件在 B 撿、一件在 C 用 |
| 卡片 | 25 張以內 | 超過就砍場景，不砍測試時間 |
| 結局 | 1 個通關加 1 個沒通關 | 沒通關的也要能重來，不能卡死 |
| 語音 | 最後才配，可以沒有 | 先確定互動對，再挑聲音 |

**二、劇情（這一段人來填）**

- **一句話題材**：誰、在哪、要做到什麼才能離開。
- **通關那一刻玩家明白了什麼**：謎案是倒著寫的，先寫這一句。
- **場景 A**：名稱、背景一句描述、可以點的東西、撿到的物品 ①。
- **場景 B**：名稱、背景一句描述、用物品 ① 打開什麼、撿到的物品 ②。
- **場景 C**：名稱、背景一句描述、用物品 ② 通關；缺物品時的提示句。
- **要回頭的地方**：哪一條線索要回 A 或 B 才拿得到，這就是官方說的場景往返。
- **角色**：名字、一句識別特徵（髮型、髮色、一件固定配件）、跟玩家的關係。

**三、規則（貼給 Agent 的那幾條）**

1. 物品用背包插件收，撿到就進背包，不消耗的標「重要物品」。
2. 走錯場景不會死：沒東西可用時給一句提示，把玩家送回選場景的那張卡。
3. 每個場景都從「選場景」那張卡進出，來回不丟進度。
4. 兩個結局都標成結局；通關結局解鎖一張 CG 進圖鑑。
5. 先交無語音版，播一遍確認三件物品的順序對了，再配音。試玩用預覽連結（有時效），確定了再發佈拿市集網址。
6. 卡片文字用正體中文、全形標點。

**四、驗收（試玩回饋時照這六格勾）**

1. A 撿 ① → B 用 ① 撿 ② → C 用 ② → 通關，這條走得通
2. 先去 C 什麼都沒帶，有提示，不卡死
3. 去 B 沒帶 ①，一樣有提示
4. 背包裡的名稱跟畫面上看到的一致
5. 通關後圖鑑多一張
6. 沒通關的結局能回標題重來

**填好的範例：《關店前十分鐘》**

深夜便利商店，店長送急診、手機打不通，工讀生第一次自己關店，鐵門密碼只有店長知道。謎底：店長記性差，每天早上開店時自己把密碼改成前一天關東煮賣出的數量（不足四位補零）當記法，備忘鎖在自己的儲物櫃。A 櫃台的遺失物盒有一支綠標籤小鑰匙（店長下午掉的）；B 後場倉庫的儲物櫃要那支鑰匙才開得了，裡面是他給自己的備忘「鐵門＝昨天黑輪賣出數，不足四位補零」；C 店門口的密碼鎖要有備忘，數字得回 A 開 POS 日報查。同事阿哲一個立繪，只給兩個提示不給答案；密碼錯三次警報響，保全來開門，那是沒通關的結局。素材用內建的「午夜頻率」包。現場談不出題材就直接用這份，只改題材與角色。
