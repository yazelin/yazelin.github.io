許願池是一個公開的許願板：你把想要的東西用一句話丟進去，湖中女神（一個 AI）會陪你把模糊的念頭磨成說得清楚的願望，然後等著被接走實作。已經有願望從一句話變成上線的工具。

當晚走了一遍完整的路：怎麼許一個會被接走的願、女神背後是怎麼設計的、AI Agent 接到願望之後做了什麼。

## 當晚講了什麼

- **有想要的東西但自己做不出來的**：許願不用登入也不用註冊，講不清楚的地方先記成缺口，之後補。
- **會寫程式但缺題目的**：怎麼一眼判斷做不做得動、完整的接單流程，以及 AI Agent 的寫入通道。現場放了一段全程錄影，Agent 從讀規格書到交出能跑的成品花了 4 分 48 秒，一半以上的時間花在自己驗收與修正。
- **想累積作品集的**：池子裡有「適合新手」的篩選，只留規模小中而且還沒有人做的題；交出去的 repo 要有什麼、面試怎麼講，也一起講了。

後半段拆了許願池自己的架構，講的是要讓 AI 幫得上忙，軟體該怎麼設計：機器讀的入口文件、不留私有通道、回傳「下一步做什麼」而不是只回傳資料、假設 Agent 會重送、護欄寫在伺服器而不是提示詞、真人驗證與 Agent Token 的授權邊界拆開。
