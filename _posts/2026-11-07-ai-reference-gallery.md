先說授權：這四個圖庫裡，只有一個是 CC0。

我原本以為今天看到的三個新站都是 CC0，結果 AI 把四個站的注意事項逐條抓下來對過，回報只有臉部站是 CC0。這件事影響了網站和 skill 的做法。

## 這是給誰用的

給用 AI 生圖、生影片，又想讓角色保持一致的人。

想讓角色一致，通常要分開控制動作、穿著、長相。每一件都可以丟一張參考圖進去，但要先有圖可以丟。這四個日文圖庫各管一件：

| 圖庫 | 內容 | 管什麼 |
|---|---|---|
| 姿勢集 POSE-DB-01 | 無臉灰色人台線稿 1,439 張，288 個姿勢，大多有 5 個角度 | 動作 |
| depth 姿勢集 POSE-DB-02 | 同一批姿勢的深度圖 1,439 張，越白越靠近鏡頭 | 動作（給吃深度圖的工具） |
| 服裝集 COSTUME-DB-01 | 只有衣服、沒有人的圖 1,407 套，分春夏秋冬、內衣、派對、泳裝、性感 | 穿著 |
| AI 模特兒臉部資料庫 | AI 生成的虛構人物 1,499 張，正面素色背景的「臉部」893 張、看得出服裝氛圍的「造型」606 張 | 長相 |

前三個的作者是ギア，臉部庫是あぎ。原站都是日文，分類、姿勢名稱、髮型都是日文，搜尋也只能用日文或英文。

統一入口在這裡：<https://yazelin.github.io/ai-reference-gallery-zh-tw/>

## 授權到底寫什麼

10/29 那篇[替格莉奇做自介短片]({% post_url 2026-10-29-glitch-intro-video %})的早上，先做了姿勢集的繁中版。那時候讀過注意事項：可以免費用在自己的作品、可以商用、不用標出處，但禁止再散布圖片本身。所以那個版本只翻網頁，圖片一張都沒放，全部從原站載入。

今天看到另外三個站，四個一起對：

- 姿勢、depth、服裝三站（ギア）：一樣禁止再散布圖片。另外多了一條：禁止批次下載，用工具自動抓取也算，生成時一張一張拿來參考可以。原站原始碼的註解寫著，頂端那行禁止提示是 10/30 加的，最早那個姿勢站也有了。
- 臉部站（あぎ）：CC0 1.0，可以自由使用。但同一頁也寫了「請不要再散布、轉載圖片資料本身」，後面括號註明是「お願い」，請求的意思。

臉部站雖然是 CC0，同一頁也請大家不要再散布圖片，所以四個站用同一套做法：只翻網頁、不放圖。

批次下載那條影響比較大。給 AI 用的 skill 有一個下載指令，現在一次最多只能拿 10 張，超過直接擋掉。每天同步也只抓網頁和資料（HTML、JS、CSS），不碰圖片。

## 四個合成一個

本來是一個 repo 只放姿勢集，叫 `ai-pose-gallery-zh-tw`。我讓 AI 把它改名成 `ai-reference-gallery-zh-tw`，四個圖庫放在同一個網站的四個子路徑，首頁當入口。

翻譯的部分，四站共用一份日文對中文的對照表。原本姿勢集那份就有了，depth 站跟姿勢站是同一批姿勢，對照表幾乎直接沿用。新補的大約 260 條，主要是服裝的單品、顏色、材質，和臉部的髮型名稱，其餘是介面和注意事項的文字。

有幾個地方不是直接翻：

- 服裝的關鍵字原本是英文（`ivory frill knit denim mini skirt`），原站有一份日文對英文的搜尋對照，像「白」對 `white`、「コート」對 `coat`。把這份對照也翻成中文，搜「白 大衣」就會找到有白色單品的大衣穿搭。
- 臉部站的髮長分類，ミディアム 跟 セミロング 直翻都是「中長」，分不出來。ミディアム 改成「及肩」，セミロング 留「中長髮」。
- 臉部站在看大圖和下載時，會把圖片 ID 送到網站自己的 `/api/hit`。繁中版沒有這支 API，所以把呼叫關掉。
- 姿勢、depth、服裝三站的 Cloudflare 流量分析也拿掉，避免把繁中版的流量算進原作者的統計。姿勢站在 10/29 那版就拿掉了。

改名之後，舊網址會變成 404，10/29 那篇文章就連過去。所以另外用舊名字開一個轉址用的 repo：舊網址轉到新的姿勢集，舊的 `poses.json` 每天從新站複製一份，之前裝過舊版 skill 的人照常能用。代價是 GitHub 改名後原本會自動轉址的 git 網址，現在會指到這個轉址 repo。

## 給 AI 用的 skill

網頁是給人看的。AI 要用的話，讀 `llms.txt` 或裝 skill：

```bash
git clone https://github.com/yazelin/ai-reference-gallery-zh-tw.git
ln -s "$PWD/ai-reference-gallery-zh-tw/skills/reference-gallery" ~/.claude/skills/reference-gallery
```

裝好之後可以直接用中文查（在 skill 目錄裡執行）：

```bash
python3 ref.py search pose 站立 --line 全身1人・標準系 --angle 斜側
python3 ref.py search costume --cat 泳裝
python3 ref.py search portrait --section face --hair 長髮
python3 ref.py get costume SWM-0004 -o refs
```

不想裝的話，對 AI 說「讀 <https://yazelin.github.io/ai-reference-gallery-zh-tw/llms.txt>，幫我找一個跪坐回頭的姿勢」也可以。

## 拼一張看看

做完之後我問 AI：要不要組合起來畫一張泳裝看看？

它用 skill 挑了三張：

- 姿勢：`full_single_P029_diag`，標準系的「站立・讓頭髮飄動」，斜側角度。一手放到頭後面，一手叉腰。
- 服裝：`SWM-0004`，淺藍連身泳裝，肩帶綁蝴蝶結、胸前有挖空，配藍白碎花雪紡沙龍、草帽、楔型涼鞋、草編包。
- 臉部：`f000fa12e8d`，長髮的成年女性。

三張一起丟給 codex 內建的生圖工具，要一張寫實的海邊全身照。

第一次被 OpenAI 的安全過濾擋掉。codex 自己改寫重試，多加了不煽情、穿著保守、布料不透光的描述，又被擋。兩次的錯誤訊息都是 `moderation_blocked`，類別寫 sexual，而且是在出圖之後判定的，也就是圖畫出來了，才被認定成性內容擋下。

第三次改成插畫風格、寫明是虛構人物，三張參考圖照樣放，這次生出來了。就是最上面那張。

拿成品跟三張參考圖對：

- 服裝最準。肩上的蝴蝶結、胸前挖空、沙龍的碎花和打結的位置、草帽上的藍緞帶，連草編包上綁的那條絲巾都有。挖空和包上的絲巾提示詞沒寫，是從參考圖拿的。
- 姿勢的手對了，一手放在頭後面、一手叉腰。腳的距離差不多，但腿被沙龍蓋住，參考圖膝蓋往外開的樣子看不出來。
- 臉留下長的棕色頭髮、棕色眼睛、微笑，畫風變成插畫。這三項提示詞裡也寫了。

這次只試了一組：寫實版被擋，插畫版有出來。

參考圖本身不能再散布，生出來的作品可以用。這篇文章裡只放生成的那張，三張參考圖請到原站看。
